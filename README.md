## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The Loader workspace starts at [http://localhost:3000/loader](http://localhost:3000/loader). Its nine screens follow the Figma Loader mobile flow and adapt to tablet and desktop layouts. Loader styles and assets are scoped separately from the existing Store Manager pages.

This is a frontend demo: shortfall reports, plan acknowledgements, and departure state persist in the current browser tab. “Check dispatch decision” advances to the approved demo state; it does not contact a dispatch service. “Call Dispatch” displays the contact because no dispatch phone number is configured.

Run `npm run test:loader` for Loader asset and workflow checks, `npm run lint` for code checks, and `npm run build` for the production build.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
